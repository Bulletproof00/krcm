# Tunnels of the Underworld (TOU)

A fast, uncompromising 2D arcade action game with multiplayer focus.

## Features

- Up to 64 ships simultaneously (4 human players + 60 AI bots)
- 47 unique weapons across 5 categories (Laser, Ballistic, Rockets, Explosives, Special)
- Procedurally generated tunnel/cave/arena levels
- Scalable AI difficulty (1-5)
- Deathmatch & Team Deathmatch modes
- Local multiplayer (4 players on one keyboard)
- Procedural audio (sound effects + music)
- Particle effects, explosions, screen shake
- Minimap, scoreboard, kill feed, HUD

## How to Play

Open `index.html` in a modern browser. No build step required.

## Controls

| Player | Move | Rotate | Shoot | Switch Weapon |
|--------|------|--------|-------|---------------|
| P1 | WASD | Q/E | Space | F |
| P2 | Arrows | ,/. | Enter | Right Shift |
| P3 | IJKL | U/O | P | ; |
| P4 | Numpad 8456 | 7/9 | Numpad 0 | Numpad . |

**ESC** = Pause | **TAB** = Scoreboard
